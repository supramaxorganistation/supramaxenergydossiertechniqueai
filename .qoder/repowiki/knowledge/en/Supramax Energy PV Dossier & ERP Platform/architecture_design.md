The workspace is organized as a flat project with a single `server/` directory containing the Express.js application; child modules are not present here — the `apps/` folder exists but is empty in this scope. Cross-cutting concerns (MongoDB driver dependency via top-level `package.json`, `.env` for secrets, `uploads/` for generated PDFs/datasheets, and `dev.out.log` / `dev.err.log` for runtime output) sit at the root so the server process can access them directly.
