Single-process Node.js server built on Express with Mongoose for MongoDB persistence. `server.js` is the application entry point: it defines core schemas (User, Dossier, Item, Equipment), registers middleware (CORS, JSON parsing, JWT auth via `authMiddleware` + `authorizeRoles`), and mounts all routes directly on the app instance under `/api/*`. The ERP subsystem is isolated in `erpRoutes.js`, which exports an Express Router mounted at `/erp` after global auth; it declares its own set of schemas (Customer, Supplier, Product, Warehouse, SalesOrder, PurchaseOrder, Invoice, Payment, Account, JournalEntry, StockMovement, Employee, Attendance) and provides full CRUD plus dashboard stats. Business logic is split into three sibling modules: `services/aiScanner.js` calls Google Generative AI (`gemini-2.5-flash`) to extract panel/inverter/protection/cable specs from uploaded PDFs; `utils/stegCalculations.js` implements NF C 15-100 cable sizing, voltage drop, wind stability, and protection checks returning a structured compliance report; `services/pdfGenerator.js` fills the official STEG template PDF using `pdf-lib` and merges annexes. File uploads go to a local `uploads/` directory served statically via `express.static('uploads')`. Configuration is loaded from `.env` (PORT, JWT_SECRET, MONGO_URI, GEMINI_API_KEY).
